# Фронтенд-приложение GeoReviews (Vue 3 + Vite + TypeScript)

Клиентское одностраничное веб-приложение (SPA) для визуализации данных организаций на Яндекс.Картах, анализа отзывов, просмотра истории снимков репутации и администрирования пула прокси-серверов.

---

## 🚀 Стек технологий и архитектура

- **Фреймворк**: [Vue 3](https://vuejs.org/) (Composition API, синтаксис `<script setup>`).
- **Язык программирования**: [TypeScript](https://www.typescriptlang.org/) со строгой типизацией (**строгий запрет использования `any`**).
- **Сборщик**: [Vite](https://vite.dev/) с HMR и оптимизированным чанкованием сборки.
- **Управление состоянием**: [Pinia](https://pinia.vuejs.org/) (модульные типизированные сторы).
- **Маршрутизация**: [Vue Router 4](https://router.vuejs.org/) с Navigation Guards (защита маршрутов и ролевой доступ `is_admin`).
- **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/) с адаптивным интерфейсом и темной/светлой темой.
- **Сетевой уровень**: [Axios](https://axios-http.com/) с интерцепторами токенов Bearer и сквозного Correlation ID (`X-Request-ID`).

## 🌟 Ключевые возможности интерфейса

1. **Реактивный Live Progress Bar с текстовыми статусами**:
   - Автоматический опрос (`polling` с адаптивным интервалом 1.2 с) статуса карточки при синхронизации.
   - Живая индикация процентов сбора данных (`sync_progress`) и детального шага (`sync_message`), информирующего о переходе по страницам.
   - Четкое предупреждение о безопасном лимите сбора (до 600 актуальных отзывов / 12 страниц) для предотвращения бана IP и SmartCaptcha Яндекса.
2. **Умный полнотекстовый поиск с подсветкой совпадений**:
   - Мгновенный поиск по отзывам, авторам и ответам компании с подсветкой найденных фраз (`<mark>`) без уязвимостей XSS.
3. **SVG-график динамики репутации (`ReputationTrendChart`)**:
   - Чистый легковесный компонент без внешних библиотек (Chart.js/D3), рассчитывающий динамический масштаб шкалы, точки значений и замкнутый градиентный контур заливки.
   - Поддержка переключения метрик: динамика рейтинга (★) и рост числа отзывов (💬).
   - Интерактивный демонстрационный режим готового примера графика за 60 дней с подсказками при недостатке снимков.
4. **Полноценная пагинация и фильтры отзывов**:
   - Вывод строго по 50 отзывов на страницу с фильтрацией по звездам (1–5) и переключением режимов сортировки.
5. **Бесшовный экспорт в Excel**:
   - Скачивание CSV файла с кодировкой UTF-8 BOM в 1 клик без битой кириллицы.
6. **Административный центр**:
   - Мониторинг здоровья системы и пула прокси в реальном времени.
   - Пакетный ввод адресов прокси с валидацией форматов.
7. **Система Toast-уведомлений**:
   - Информативные нотификации об успехе или ошибке с возможностью скопировать технический `Trace ID` для отладки.

## 🛠 Запуск и разработка

```bash
# 1. Установка npm-зависимостей
npm install

# 2. Запуск сервера для локальной разработки (Vite HMR)
npm run dev

# Приложение доступно по адресу: http://localhost:5173
```
